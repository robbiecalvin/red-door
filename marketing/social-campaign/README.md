# Badehaus X four-week launch campaign

Use [posting-calendar-4-weeks.csv](posting-calendar-4-weeks.csv) for the expanded campaign. It covers November 23 through December 20, 2026, with two posts a day on Instagram, Facebook and X. Times use America/Vancouver. Shift the dates together if the launch moves.

Each row includes a ready-to-copy caption with hashtags, a relative image path, alt text and a tracked link. Instagram captions direct readers to the profile link. Set that link to Badehaus X during the campaign. Facebook and X captions include the tracked link in the copy.

The [launch ad index](launch-ads/ad-index.csv) lists 30 square flyers and their QR destinations. The [contact sheet](launch-ads-preview.jpg) shows all 30 at a glance. The flyers use the Badehaus X launch artwork and the public signup offer code **BADEHAUSXONLINE**. Review the offer before reusing these flyers after the campaign window.

The original [posting calendar](posting-calendar.csv) is included for reference. Use the expanded calendar for scheduling.
